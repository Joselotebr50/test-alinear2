💻 Código para usar no seu projeto

composicao.css 
/* Container principal - sem gaps! */
.unidade-visual {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0;  /* ← Sem espaço entre imagens */
  width: 100%;
  overflow: hidden;
}

/* Cada imagem */
.unidade-visual img {
  width: 100%;
  height: auto;
  display: block;
  object-fit: cover;
}

/* Mobile: empilha verticalmente */
@media (max-width: 768px) {
  .unidade-visual {
    grid-template-columns: 1fr;
  }
}

💡 Dicas para suas imagens

🎨

Planeje as bordas

As bordas das imagens devem se conectar. Use Photoshop para dividir uma imagem panorâmica em 3 partes iguais.

📐

Mesma altura

Todas as imagens devem ter a mesma altura para ficarem alinhadas perfeitamente.

📱

Teste em mobile

Em telas pequenas as imagens empilham. Verifique se cada imagem funciona bem sozinha.

⚡

Otimize o tamanho

Use imagens otimizadas (WebP, compressão) para carregamento rápido em qualquer dispositivo.
